## 🚀 Deploy in 3 Steps (5 Minutes)

### Option 1: Render.com (RECOMMENDED - Frontend + Backend Together)

**Step 1:** Go to https://render.com

**Step 2:** Click "Get Started" → Sign up with GitHub

**Step 3:** Deploy your app:
1. Click "New +" button (top right)
2. Select "Blueprint"
3. Connect to GitHub (if not already)
4. Select repository: `Bhuvaneshwari244/Aura`
5. Click "Apply"

**Done!** Your app will be live in ~10 minutes at:
- Frontend: `https://aura-frontend.onrender.com`
- Backend: `https://aura-backend.onrender.com`

📖 Detailed guide: See `RENDER_DEPLOYMENT.md`

---

### Option 2: Vercel (Frontend Only - Need Separate Backend)

**Step 1:** Go to https://vercel.com

**Step 2:** Import your GitHub repository

**Step 3:** Configure:
- Root Directory: `frontend`
- Framework: Create React App
- Deploy

📖 Detailed guide: See `VERCEL_DEPLOYMENT_FIX.md`

---

### Option 3: Firebase (Frontend + Backend Functions)

**Step 1:** Install Firebase CLI:
```bash
npm install -g firebase-tools
```

**Step 2:** Login and deploy:
```bash
firebase login
firebase deploy
```

📖 Detailed guide: See `FIREBASE_DEPLOYMENT_GUIDE.md`
